# سامانه جامع حسابداری سالن مطالعه پسرانه «فخرآوران» (PWA + GitHub Cloud Sync)

## فایل‌های موجود در پکیج
- `index.html`: فایل اصلی اپلیکیشن (شامل تقویم شمسی تعاملی، آپلود لوگوی اختصاصی و اتصال ابری به گیت‌هاب با توکن)
- `manifest.json`: مانیفست نصب وب‌اپلیکیشن (PWA) روی اندروید، iOS و دسکتاپ
- `sw.js`: سرویس‌ورکر برای اجرای آفلاین و نصب به صورت اپ مستقل
- `icon-192.svg` و `icon-512.svg`: آیکون‌های استاندارد سرمه‌ای و طلایی اپ

## راهنمای نصب روی GitHub Pages و اتصال توکن ابری
1. یک ریپازیتوری جدید در گیت‌هاب بسازید و فایل‌های داخل این پکیج را در آن آپلود کنید.
2. از بخش **Settings > Pages** در گیت‌هاب، شاخه `main` را فعال کنید تا لینک وب‌اپ شما ساخته شود.
3. برای فعال‌سازی **ذخیره ابری خودکار (Cloud Sync)**:
   - در گیت‌هاب به مسیر **Settings > Developer settings > Personal access tokens > Tokens (classic)** بروید.
   - یک توکن جدید با تیک دسترسی **`repo`** یا **`gist`** بسازید.
   - داخل برنامه فخرآوران به تب **تنظیمات** بروید، توکن و نام ریپازیتوری (`username/repo`) را وارد کرده و تیک **«ذخیره ابری خودکار پس از هر تغییر»** را فعال کنید.
